# atelier-alchemy-core コンテキストノート

**作成日**: 2026-07-09

## 背景

「アトリエ錬金術ゲーム」を v7.0 コンセプト（調合主軸モデル）に基づき **一から作り直す** ための要件定義。
現行実装（`atelier-guild-rank`）の依頼・採取・庭配置パズルはコンセプト上すでに廃止決定済みであり、
本要件定義では現行コードの詳細分析は行わず、`docs/concept/atelier-concept.md`（v7.0）を一次情報として要件化した。

## 参照した文書

- `docs/concept/atelier-concept.md`（v7.0） — 一次情報。庭・調合・納品・金の使い道の確定仕様が記載
- `docs/concept/experience-core.md`（v4.0） — 旧モデル（依頼受注制）の体験コア。v7.0時点で未更新。要件定義には直接使用していないが、後続で体験コア文書の更新が必要（コンセプト文書「次のステップ」参照）
- `docs/spec/atelier-guild-rank-requirements.md`（v1.6） — 現行有効だが依頼・採取モデルの要件定義。EARS記法の書式（REQ-XXX番号体系）のみ参考にし、内容は採用していない
- `docs/spec/INDEX.md` — 仕様ドキュメントの世代管理表。本書完成後に追記が必要

## 技術スタック（未決定・重要）

- 現行 `atelier-guild-rank` は Phaser 3 + TypeScript + pnpm モノレポ（`CLAUDE.md` 参照）
- ヒアリングでは「維持するか変更するかは別途検討」という回答であり、**本要件定義では技術スタックを前提としていない**
- 次フェーズ（`/tsumiki:kairo-design` 等の技術設計）で確定させること。requirements.md の NFR-301 に要確認事項として明記済み
