# ゲームコンセプト: アトリエ錬金術ゲーム

作成日: 2025-12-21
更新日: 2026-07-05
バージョン: 6.0

> ⚠️ **v6.0 は大きな設計転換です。** 「採取（採取地カード）」を「庭（栽培）」に、「依頼システム」を「調合物の直接ギルド納品」に置き換え、v5.0のAP・フェーズ自由遷移をシンプルなターン制に戻しています。現行実装（`free-phase-navigation` / 依頼・採取システム）とは乖離するため、実装反映には大規模な作り直しが必要です。

## 1. ワンセンテンス・コンセプト

> 【誰が】【何をして】【どんな判断を繰り返し】【どんな感情になるゲームか】

```
錬金術師（プレイヤー）が
グリッド状の庭に素材を植えて育て、成長した素材をレシピで調合し
限られた庭の広さと「何をどこに植えるか（隣接シナジー）」をやりくりしながら
「何を育て、何を作り、貢献度と報酬のどちらを優先するか」を判断し
調合物をギルドに納めてランクを上げていくことで
「庭づくりの工夫」と「トレードオフの判断」「ランクアップの達成感」を味わうゲーム
```

**短縮版（30秒説明）:**
> グリッド状の庭に種を植えて素材を育て、収穫して調合し、ギルドに納めてランクを上げていく錬金術師RPG。庭の広さと配置（隣接シナジー）をやりくりして「育てる素材の組み立て」を作り、貢献度を稼ぐか報酬を稼ぐかを判断する。バックパックバトルのような配置構築＋栽培が肝。

**キャッチコピー:**
> 「庭で育てて、調合して、ギルドに納めて、ランクを上げろ。」

```
    ランクを進めるか、稼いで庭・デッキを強化するかを迫られる
```

### 1プレイ全体（60〜90分）

| ランク | 時間目安 | 判断内容 | 判断の重さ |
|--------|---------|---------|-----------|
| G | 00:00-10:00 | チュートリアル、植える→育てる→調合の基本を学ぶ | 軽い |
| F | 10:00-25:00 | 庭の配置と調合のバランスを学ぶ | 軽〜中 |
| E | 25:00-40:00 | 隣接シナジーと成長速度を意識し始める | 中 |
| D | 40:00-55:00 | 品質要求・貢献度と報酬の配分に対応 | 中〜重 |
| C-B | 55:00-75:00 | 限られた庭でシナジーを最大化、効率化 | 重い |
| A-S | 75:00-90:00 | ギリギリの構築判断、最終試験 | 最大 |

### 1ランク内（10〜20分）

| HP残量 | フェーズ | 判断内容 | 緊張感 |
|--------|---------|---------|-------|
| 100〜75% | 序盤 | 庭を整え、育てる素材を仕込む | 低 |
| 75〜50% | 前半 | 収穫→調合→納品で安定して貢献 | 中 |
| 50〜25% | 後半 | 庭のレイアウト調整、配置の最適化 | 高 |
| 25〜0% | 終盤 | 昇格試験に向けた貢献度の追い込み | 最大 |

### 緊張感カーブ

- **Gランク**: チュートリアル、余裕を持って学習
- **F-Eランク**: 基本ループ（栽培→調合→納品）に慣れる
- **D-Cランク**: 品質と貢献度／報酬配分の厳しさが増す
- **B-Aランク**: 限られた庭での高効率構築、シビアな判断
- **Sランク**: 最終試験、降格リスクあり

## 5. ゲームサイクル

### メインループ（庭・ターン制モデル）

AP・フェーズ自由遷移は廃止し、シンプルなターン制に回帰。プレイヤーの能動的な判断は
**「庭のレイアウト」** と **「何を調合するか（貢献度優先か報酬優先か）」** の2点に集約し、
収穫・納品は自動で処理する。

```
┌──────────────────────────────────────────────────────┐
│                       状況把握                        │
│  ランクHP・庭の状態・素材在庫・成長中の作物を確認     │
└──────────────────────────────────────────────────────┘
                        ↓
    ┌──────────────────────────────────────────┐
    │  ① 庭を整える（配置構築 / バックパック型） │
    │     手持ちの種・苗をグリッドに配置          │
    │     ・広さの範囲で「何を育てるか」を選ぶ    │
    │     ・隣接シナジーを狙って配置する          │
    └──────────────────────────────────────────┘
                        ↓
    ┌──────────────────────────────────────────┐
    │  ② 調合する（レシピ選択）                  │
    │     収穫済み素材でレシピを選び調合          │
    │     ・貢献度が伸びる品 or 報酬が伸びる品     │
    └──────────────────────────────────────────┘
                        ↓
    ┌──────────────────────────────────────────┐
    │  ③ ターン経過（自動処理）                  │
    │     ・作物が1ターン分成長（種別＋乱数）     │
    │     ・成熟した作物を自動収穫 → 素材在庫へ   │
    │     ・調合物を自動でギルドへ納品            │
    │       → 貢献度（ランクHPにダメージ）＋報酬  │
    └──────────────────────────────────────────┘
                        ↓
             ランクHP0？ → 昇格試験へ！
                        ↓
       （必要なら）ショップで種・レシピ・庭拡張を購入
                        ↓
                    次のターンへ
```

### 庭（栽培）の仕組み

- **グリッド配置**: 庭はマス目状。手に入れた種・苗を配置する（バックパックバトル型）
- **広さ制限**: 育てられる素材の数は庭の広さで制限。ショップで庭を拡張できる
- **入れ替え**: 植える素材はいつでも組み替え可能（デッキ構築的判断）
- **成長速度**: 素材の種類ごとに成長ターン数が異なる（早い＝薬草、遅い＝希少鉱石 等）
- **乱数変動**: 毎ターンの成長量・収穫できる素材は乱数で変動し、同じ庭でも結果が揺れる
- **隣接シナジー**: 隣り合う素材の組み合わせで、成長速度・品質・収穫量にボーナス／ペナルティが発生
- **自動収穫**: 成熟した作物はターン経過時に自動で収穫され、素材在庫に入る

### ギルド貢献の仕組み（依頼廃止 → 調合物の直接納品）※提案

- 依頼受注は廃止。**作った調合物はそのままギルドへ自動納品**される
- 各調合物は2つの価値を持つ:
  - **貢献度**: ランクHP（敵）を削る＝ランクアップに直結（短期の前進）
  - **報酬（ゴールド）**: ショップでの種・レシピ・庭拡張の購入原資（長期の強化）
- 調合物ごとに「貢献度が伸びやすい品」と「報酬が伸びやすい品」があり、
  **今ランクを押し上げるか、稼いで庭・デッキを強くするか**のトレードオフが生まれる
- 品質（D〜S）が高いほど貢献度・報酬とも増加する

> 💡 この貢献度／報酬・ランクHPの扱いは提案です。ずんだもんの案では「ランクHP（敵）モデルを維持し、
> 調合物の貢献度でHPを削る」構成にしていますが、調整したい場合は指示してほしいのだ。

### 状況に応じた判断の例

| 状況 | 優先すべき判断 | 理由 |
|------|--------------|------|
| ゲーム開始時 | 庭に何を植えるか決める | 育てないと素材が手に入らない |
| 庭に空きがある | 隣接シナジーを狙って配置 | 配置の工夫で効率が大きく変わる |
| 素材が揃った | 調合するレシピを選ぶ | 何を作るかで貢献度／報酬が変わる |
| ランクアップを急ぎたい | 貢献度が伸びる調合物を優先 | ランクHPを速く削れる |
| 庭・デッキを強化したい | 報酬が伸びる調合物を優先 | ゴールドで拡張・強化に投資 |
| 庭が手狭 | ショップで庭を拡張 | 育てられる素材の幅が広がる |
| 成長が遅い | 早く育つ素材へ入れ替え | 収穫ペースを上げる |

## 7. バージョン変更履歴

### v6.0 主要変更点（庭・栽培モデルへの転換）

| 要素 | v5.0 | v6.0 |
|------|------|------|
| 素材供給 | 採取地カードで採取 | **庭で栽培（種を植えて育てて収穫）** |
| デッキ構築 | 採取地＋レシピの2系統デッキ | **庭のグリッド配置（バックパックバトル型）＋レシピ** |
| 配置要素 | なし | **隣接シナジー・広さ制限・庭拡張** |
| 成長・乱数 | なし | **素材ごとの成長速度＋乱数で収穫内容が変動** |
| 依頼 | 掲示板＋訪問で受注→納品 | **廃止 → 調合物を直接ギルドへ自動納品** |
| 貢献の仕組み | 依頼達成で貢献度 | **調合物ごとの貢献度／報酬トレードオフ** |
| 時間モデル | AP × フェーズ自由遷移 | **シンプルなターン制（収穫・納品は自動）** |
| 判断の核心 | 時間（AP）の段取り | **庭の配置構築 ＋ 貢献度/報酬の選択** |

### v6.0 からの変更理由

- **配置構築の面白さ**: バックパックバトル型のグリッド配置＋隣接シナジーで「構築の工夫」を作る
- **栽培のテーマ性**: 「錬金術師の庭で素材を育てる」という世界観に沿った素材供給
- **判断の明確化**: 依頼・APを削り、「何を育て・何を作り・貢献度か報酬か」に判断を集中
- **手触りの軽量化**: 収穫・納品を自動化し、配置と調合の思考に集中させる
- **⚠️ 注意**: v5.0の`free-phase-navigation`・依頼・採取システムからは大きく乖離。実装には大規模な作り直しが必要

### v5.0 主要変更点（フェーズ自由遷移モデル）

| 要素 | v4.0 | v5.0 |
|------|------|------|
| フェーズ遷移 | 固定順序（受注→採取→調合→納品） | **タブで自由遷移（順序自由）** |
| 日数進行 | 「日終了」ボタンのみ | **AP超過による自動日進行 ＋ 日終了ボタン** |
| AP回復 | 日開始時に上限(3)まで完全回復 | **上限(3) − 前日超過分で回復** |
| 採取フェーズ | 直接ドラフト採取 | **場所選択 → ドラフト採取の2段階** |
| 依頼入手 | 毎日新しい依頼者が来訪 | **掲示板（累積）＋ 訪問（3日更新）の併用** |
| フェーズUI | プログレスバー | **タブ切り替えUI** |
| 判断の核心 | デッキ構築＋行動選択 | **＋「時間（AP）の段取り」** |

### v5.0 からの変更理由

- **戦略的自由度の向上**: 固定手順をやめ、プレイヤーが行動の順序と配分を設計できるようにした
- **時間のリソース化**: AP超過で日が進むモデルにより、「今日どこまでやるか」という新たな判断軸が生まれる
- **採取体験の深化**: 「どの採取地へ行くか」という場所選択の意思決定を追加
- **設計根拠**: [フェーズ自由遷移システム要件定義](../spec/free-phase-navigation/requirements.md) に基づく

### v4.0 主要変更点

| 要素 | v3.1 | v4.0 |
|------|------|------|
| キャッチコピー | 「受けて、採って、混ぜて、届けろ。」 | 「**依頼を受けて、素材を採って、調合して、ランクを上げろ。**」 |
| 目標 | 開拓度100%×3 | **ギルドランクHP削り→昇格試験→ランクアップ** |
| 敵 | 消耗度（自傷） | **ギルドランク（外敵）** |
| デッキ構成 | 5系統カード | **採取地カード＋レシピカードの2系統** |
| 素材管理 | カードとして扱う | **インベントリ管理（消費制）** |
| 依頼 | 納品で効果発動 | **納品で貢献度（ダメージ）獲得** |
| 進行感 | 開拓地クリア | **ランクアップ（G→S）** |
| 達成感 | バーを埋める | **敵を倒す、昇格試験クリア** |

### v3.1 からの変更理由

- **戦闘感の強化**: 「敵を倒す」という明確な目標
- **達成感の明確化**: ランクアップという区切り
- **成長の可視化**: 解放要素（採取地・レシピ）による進行感
- **デッキの意味強化**: 採取地＝行ける場所、レシピ＝作れるもの
