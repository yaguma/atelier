## タスク概要

庭の状態を表示し、種植え・収穫の操作を受け付けるUIシーン `garden_panel.tscn`（親）と `garden_slot.tscn`（スロット単位の子シーン）を実装する。ユーザストーリー1.1「調合から逆算して種を植える」・1.2「安全にBで抜くかS狙いで待つかを選びたい」がUI上で判断可能になるよう、各スロットの成熟状態・現在の推定品質・枯死までの残り猶予ターンを可視化する。architecture.mdの原則に従い、本UIは `GameState`（TASK-0024）が発行する `garden_updated` / `inventory_updated` signalを購読して表示を更新するのみで、成熟判定・品質計算・特性抽選等のビジネスロジックを一切持たない。

## 実装詳細

### 1. `garden_panel.tscn` の構成 🔵

**信頼性**: 🔵 *architecture.mdディレクトリ構造案「garden_panel.tscn」より*

`garden_panel.gd` は `GameState.garden_slot_count` 分の `garden_slot.tscn` を動的に生成・配置し、`GameState.garden_slots` の内容と同期させる。

```gdscript
# res://features/garden/ui/garden_panel.gd
extends Control

@export var slot_scene: PackedScene  # garden_slot.tscn
var _slot_nodes: Array[Node] = []

func _ready() -> void:
	GameState.garden_updated.connect(_on_garden_updated)
	_rebuild_slots()

func _rebuild_slots() -> void:
	for slot_node in _slot_nodes:
		slot_node.queue_free()
	_slot_nodes.clear()
	for i in GameState.garden_slots.size():
		var slot_node := slot_scene.instantiate()
		slot_node.setup(i, GameState.garden_slots[i])
		add_child(slot_node)
		_slot_nodes.append(slot_node)

func _on_garden_updated() -> void:
	_rebuild_slots()  # 🟡 簡易実装。パフォーマンス最適化が必要な場合は差分更新に改善する

func _exit_tree() -> void:
	if GameState.garden_updated.is_connected(_on_garden_updated):
		GameState.garden_updated.disconnect(_on_garden_updated)
```

**実装ファイル**: `features/garden/ui/garden_panel.gd`, `features/garden/ui/garden_panel.tscn`

### 2. `garden_slot.tscn` の状態表示 🔵

**信頼性**: 🔵 *ユーザストーリー1.2「安全にBで抜くかS狙いで待つか」、REQ-004, REQ-005, REQ-007より*

各スロットは以下4状態を視覚的に区別する。ロジック（成熟・枯死・品質の判定）は一切持たず、`GameState`（またはその内部で保持する経過ターン情報）から取得した値をそのまま表示する。

| 状態 | 表示内容 |
|------|---------|
| 空き | 「植える」ボタンのみ表示 |
| 成長中（未成熟） | 種の名前、成熟までの残りターン数、収穫ボタンなし（EDGE-003） |
| 成熟済み（収穫可） | 種の名前、現在の推定品質（D〜S）、枯死までの残り猶予ターン数、「収穫する」ボタン |
| 枯死 | 「枯死」表示、収穫ボタンなし、除去操作の導線（除去処理自体はTASK-0024スコープ外のため、本タスクではUI上の表示のみ） |

`garden_slot.gd` はロジックを持たず、`GameState` から取得した「成熟済みか」「枯死か」「推定品質」「残り猶予ターン」の値をそのまま表示に反映する。これらの値の算出方法（`GrowthCalculator` の呼び出し）は `GameState` 側（TASK-0024）で完結しており、UIは計算しない。

**実装ファイル**: `features/garden/ui/garden_slot.gd`, `features/garden/ui/garden_slot.tscn`

### 3. 植栽・収穫操作のイベント連携 🔵

**信頼性**: 🔵 *ui-components.mdの状態監視コンポーネントパターン、REQ-001, REQ-007より*

```gdscript
# garden_slot.gd（抜粋）
signal harvest_requested(slot_index: int)
signal plant_requested(slot_index: int)

func _on_harvest_button_pressed() -> void:
	harvest_requested.emit(slot_index)

func _on_plant_button_pressed() -> void:
	plant_requested.emit(slot_index)
```

`garden_panel.gd` が各 `garden_slot` の `harvest_requested` / `plant_requested` signalを購読し、`GameState.harvest(slot_index, rng_seed)` / `GameState.plant_seed(seed_def, slot_index)` を呼び出す。`rng_seed` の取得元（`RngService` Autoload）は `garden_panel.gd`（Imperative Shell）が担当し、`garden_slot.gd` はシード生成に関与しない。

**実装ファイル**: `features/garden/ui/garden_panel.gd`, `features/garden/ui/garden_slot.gd`

## UI/UX要件

### ローディング状態

- 本UIは同期処理のみで構成され（dataflow.md「データ処理パターン」参照）、非同期読み込みは発生しないためローディング状態は不要

### エラー表示

- 庭が満杯の状態（EDGE-002）: 新規に種を選択する導線自体を提示しない（空きスロットが存在しないため「植える」ボタンが表示されるスロットがそもそも存在しない）予防的設計とする 🟡
- 未成熟スロットへの収穫操作（EDGE-003）: ボタンの非表示・非活性化により、そもそも操作を選択できないようにする（dataflow.md「エラーハンドリングフロー」の予防的設計方針に準拠）🔵

## 注意事項

- `garden_slot.gd` は成熟・枯死・品質計算のロジックを一切持たない。全て `GameState`（TASK-0024が内部で `GrowthCalculator` を呼び出した結果）から取得した値をそのまま表示する
- 種選択UI（植える種を選ぶダイアログ等）の詳細な見た目・レイアウトは本タスクのスコープ内だが、`.claude/rules/design-guide.md`のカード・ボタンスタイル統一ルールはGodot版では別途翻訳が必要であり、本タスク時点ではプレースホルダの見た目でよい
- 枯死スロットの除去操作の実処理（`GameState`側のAPI）はTASK-0024のスコープ外として申し送りされているため、本タスクでは表示のみを実装し、除去ボタンの実処理は後続タスクまたは別Issueで扱う
