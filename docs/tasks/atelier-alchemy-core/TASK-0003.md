## 実装詳細

### 1. GUTアドオンの導入 🟡

**信頼性**: 🟡 *architecture.mdは「GUT等」と記載するのみで導入手順は明記していないため、GUT公式ドキュメントに基づく妥当な推測*

手順:
1. Godot AssetLibrary（エディタ内）または [GUT公式リポジトリ](https://github.com/bitwes/Gut) から、使用するGodot 4.xのバージョンに対応するGUTのリリースを取得する
2. `atelier-godot/addons/gut/` にアドオン一式を配置する
3. Godotエディタの「プロジェクト」→「プロジェクト設定」→「プラグイン」タブでGUTを有効化する
4. エディタ下部にGUTパネルが表示されることを確認する

**実装ファイル**: `atelier-godot/addons/gut/`（サードパーティアドオン、リポジトリにベンダリング）

### 2. GUT設定ファイルの作成 🟡

**信頼性**: 🟡 *GUT公式ドキュメントの `.gutconfig.json` 仕様から妥当な推測*

テスト対象ディレクトリ・命名規則を設定する。GUTの規約上、テストファイル名は `test_*.gd` または `*_test.gd` のいずれかの命名規則に統一する必要があるため、本プロジェクトでは既存TypeScript版の慣習（`*.test.ts`）に近い `*_test.gd` を採用する。

```json
// atelier-godot/.gutconfig.json
{
  "dirs": ["res://tests/unit/features/"],
  "should_maximize": true,
  "log_level": 1
}
```

**実装ファイル**: `atelier-godot/.gutconfig.json`

### 3. サンプルテストの作成 🔵

**信頼性**: 🔵 *完了条件「動作確認用のサンプルテストが1本作成され成功する」より*

GUTの導入自体が正しく機能することを検証するための、最小限のサンプルテストを作成する。本テストは検証専用であり、TASK-0004以降の本実装テストとは別物として扱う（後続タスクで削除または実テストへの置き換えを行ってよい）。

```gdscript
# atelier-godot/tests/unit/features/sample_gut_setup_test.gd
extends GutTest

func test_addition_returns_correct_sum() -> void:
	assert_eq(1 + 1, 2, "GUTのセットアップ検証: 1 + 1 は 2 になるべき")
```

**実装ファイル**: `atelier-godot/tests/unit/features/sample_gut_setup_test.gd`

## 動作確認要件

### 確認項目1: サンプルテストの成功確認 🔵

**信頼性**: 🔵 *完了条件「GUTパネルまたはCLIから実行して成功する」より*

**Given**: GUT導入済み、サンプルテスト作成済みの `atelier-godot/` プロジェクト
**When**: GUTパネル（エディタ内）から「Run All」を実行する、またはCLI（`godot -s addons/gut/gut_cmdln.gd -gdir=res://tests/unit/features/`）でテストを実行する
**Then**: `test_addition_returns_correct_sum` が成功（緑色）として表示される

**確認方法**: Godotエディタの手動操作、またはBashツールでのCLIコマンド実行

### 確認項目2: テストランナーの失敗検出確認 🔵

**信頼性**: 🔵 *完了条件「失敗として正しく検出・表示する」より*

**Given**: サンプルテスト作成済みの状態
**When**: サンプルテストのアサーションを一時的に `assert_eq(1 + 1, 3, ...)` のような誤った期待値に書き換えて実行する
**Then**: GUTがテスト失敗として検出し、失敗理由（期待値と実際値の差異）を表示する。確認後は元の正しいアサーションに戻す

**確認方法**: Godotエディタの手動操作またはCLI実行
