## 実装詳細

### 1. `game_balance.gd` の基本構造 🔵

**信頼性**: 🔵 *architecture.mdの対応表「GAME_CONFIG / THEME（定数） → `shared/constants/game_balance.gd`」より*

- `class_name GameBalance` を持つ、インスタンス化不要な `const` / `static` 定数クラスとして実装する
- TypeScript版 `GAME_CONFIG` の分類（報酬・コスト、制限値、ランク設定、品質パラメータ、依頼パラメータ、確率・閾値）を、本プロジェクトのv7.0コンセプトの分類（調合・庭・ギルド納品・工房強化・ランク）に合わせて再構成する
- 値は要件定義書「未確定数値一覧」に記載の通りTBDのため、暫定値（例: `0` や仮の数値）をプレースホルダとして設定し、コメントで「TBD、balance-tuning-cycleで確定」と明記する
