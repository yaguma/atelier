## タスク概要

`autoload/game_state.gd`（Imperative Shell）に、完成品を自動的にギルドへ納品する処理を実装する。REQ-201「完成した調合物をプレイヤーの手動操作なしにギルドへ自動納品」、REQ-202「納品された調合物ごとに貢献度（ランクHPへのダメージ）と報酬（ゴールド）の2つの価値を計上」を満たす。dataflow.md「機能3: ギルド納品（自動）〜ランク判定」のシーケンス図の通り、`item_crafted` signal受信をトリガーに TASK-0028で実装した `DeliveryCalculator` を呼び出し、`rank_hp` / `gold` を更新し、`guild_delivered` signalを発行するところまでを本タスクのスコープとする（ランクHP枯渇・制限ターン超過に伴う昇格/降格判定はTASK-0030で扱う）。

## 実装詳細

### 1. item_crafted signal購読による自動納品トリガー 🔵

**信頼性**: 🔵 *REQ-201「プレイヤーの手動操作なしに」、dataflow.md「機能3」シーケンス図より*

`GameState._ready()` 内で自身が発行する `item_crafted` signalを購読し、プレイヤー操作を介さずに納品処理が起動するようにする。これによりREQ-201「完成した調合物をプレイヤーの手動操作なしにギルドへ自動納品しなければならない」を満たす。

```gdscript
# res://autoload/game_state.gd （既存GameStateへの追記）

func _ready() -> void:
	item_crafted.connect(_on_item_crafted)

func _on_item_crafted(result: CraftResult) -> void:
	var bonus: float = DeliveryCalculator.check_daily_request_match(result, today_request)
	var contribution: float = result.contribution * bonus
	var reward: float = result.reward * bonus
	rank_hp -= int(contribution)
	gold += int(reward)
	guild_delivered.emit(contribution, reward)
```

**実装ファイル**: `autoload/game_state.gd`

### 2. 貢献度・報酬の2値計上 🔵

**信頼性**: 🔵 *REQ-202「貢献度（ランクHPへのダメージ）と報酬（ゴールド）の2つの価値を計上」より*

貢献度は `rank_hp` の減算（ダメージ）として、報酬は `gold` の加算として、それぞれ独立に計上する。両者は `DeliveryCalculator` が返す同一の合致ボーナス倍率を乗算した後の値を用いる（dataflow.md「機能3」の `rank_hp -= 貢献度 × 合致ボーナス` / `gold += 報酬 × 合致ボーナス` の記載通り）。

**実装ファイル**: `autoload/game_state.gd`

## 注意事項

- 本タスクはランクHP枯渇時の昇格試験移行・制限ターン超過時の降格処理（`rank_hp_depleted` / `rank_failed` signalの発行）を含まない。それらはTASK-0030で扱う
- `rank_hp` の型は `int`（data-model.md「GameState Autoload の状態構造」より）だが、`contribution` は `float` で計算されるため、減算時の丸め方（切り捨て/四捨五入）はバランス調整に影響するため実装時にコメントで明記すること
- `GameState` はAutoloadのため、GUTでのテストにはシーンツリー起動またはAutoload経由でのテストダブル注入が必要になる場合がある。純粋関数部分（`DeliveryCalculator`）との責務分離を保ち、`GameState`側のテストはsignal発行・状態更新の検証に留める
