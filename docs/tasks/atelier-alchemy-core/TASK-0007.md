> - **現時点ではGodotプロジェクトはまだスキャフォールディングされていません**（設計文書のみ存在）。実装着手はタスク分割フェーズ（`/tsumiki:kairo-tasks atelier-alchemy-core`）以降です。

### 3. Tech Stack表の扱い 🟡

**信頼性**: 🟡 *architecture.mdに具体的な表更新内容の指定はなく、既存フォーマットを踏襲した妥当な推測*

現行の「Tech Stack」表は `atelier-guild-rank`（Phaser/TS）向けの内容のみで構成されている。本タスクでは以下いずれかの方針で更新する（実装時にチームで選択）。

- 方針A: 表のタイトルを「Tech Stack（atelier-guild-rank、凍結）」に変更し、新たに「Tech Stack（atelier-godot、メイン開発）」表を追加する（Godot 4.x, GDScript, GUT等。TASK-0003のGUT導入結果を反映）
- 方針B: 既存表はそのまま残しつつ、直前に「本表は凍結版atelier-guild-rankのものです。atelier-godotの技術スタックはGodot 4.x + GDScriptです」という注記を1行追加する

いずれの方針でも、Godot版の技術スタック（Godot 4.x, GDScript, GUT）がCLAUDE.md内のどこかに明記されている状態を最終的なゴールとする。

### 4. Quick Reference（開発コマンド）セクションの扱い 🟡

**信頼性**: 🟡 *現行のQuick ReferenceがPhaser/TS版のpnpmコマンドのみのため、混同防止の観点からの妥当な推測*

現行の `pnpm dev` / `pnpm test` 等のコマンド群は `atelier-guild-rank/`（凍結）向けである。Godot版には対応するコマンド体系（GUTのCLI実行等、TASK-0003で整備済み）がまだ確立途上のため、本タスクでは最低限「本セクションのコマンドは凍結版atelier-guild-rank向けである」旨を明記し、誤って凍結版に対して新規実装を行うことを防止する。Godot版の開発コマンド一覧の本格整備は、Phase 1以降のCI・ビルドタスクで別途行う。
