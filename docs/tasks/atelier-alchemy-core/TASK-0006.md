## 実装詳細

### 1. `theme.gd` の基本構造 🟡

**信頼性**: 🟡 *architecture.mdの対応表「GAME_CONFIG / THEME（定数） → `shared/theme/theme.gd`」、design-interview.mdの「基本的な見た目調整も含める」確定事項からの妥当な推測*

- `class_name Theme` を持つ、インスタンス化不要な `const` / `static` 定数クラスとして実装する
- 現行TypeScript版の `Colors` / `DesignTokens`（`.claude/rules/design-guide.md`参照）の分類思想（背景色・テキスト色・ボーダー色・品質色・角丸・影等）を踏襲しつつ、Godot標準の `Color` 型・`Vector2`等を用いる
- 本タスクの時点では「水彩ファンタジースタイル」の厳密な再現（design-guide.md記載のパステルカラー・ふんわり影等）までは行わず、最低限の色・レイアウト調整に留める（ヒアリング確定事項）。詳細なビジュアル実装はUI実装タスク側で `theme.gd` に追記・拡張していく前提とする

**実装ファイル**: `atelier-godot/shared/theme/theme.gd`

```gdscript
# res://shared/theme/theme.gd
# UI見た目パラメータの一元管理（TypeScript版 THEME 相当）。
# 本タスク時点では最低限の色・レイアウト調整のみを定義する（design-interview.md確定事項）。
class_name Theme
extends RefCounted

# --- 色（背景・テキスト・ボーダー） ---
const COLOR_BACKGROUND_PRIMARY: Color = Color("#F5F0E6")   # 🟡 暖色系の背景。詳細デザインは後続で調整
const COLOR_TEXT_PRIMARY: Color = Color("#2E2A24")          # 🟡
const COLOR_TEXT_MUTED: Color = Color("#8A8477")            # 🟡
const COLOR_BORDER_DEFAULT: Color = Color("#D8CFBC")        # 🟡

# --- 品質グレード表示色（MaterialInstance.Quality D〜S対応） ---
const COLOR_QUALITY_D: Color = Color("#9E9E9E")  # 🟡
const COLOR_QUALITY_C: Color = Color("#7CB342")  # 🟡
const COLOR_QUALITY_B: Color = Color("#42A5F5")  # 🟡
const COLOR_QUALITY_A: Color = Color("#AB47BC")  # 🟡
const COLOR_QUALITY_S: Color = Color("#FFB300")  # 🟡

# --- フォントサイズ ---
const FONT_SIZE_HEADING: int = 24   # 🟡
const FONT_SIZE_BODY: int = 16      # 🟡
const FONT_SIZE_CAPTION: int = 12   # 🟡

# --- スペーシング ---
const SPACING_SMALL: int = 4    # 🟡
const SPACING_MEDIUM: int = 8   # 🟡
const SPACING_LARGE: int = 16   # 🟡

# --- 角丸（design-guide.mdの角丸基準を踏襲する場合の参考値。詳細適用は後続UI実装で） ---
const RADIUS_BADGE: int = 6     # 🟡
const RADIUS_CARD: int = 12     # 🟡
const RADIUS_BUTTON: int = 18   # 🟡
```

### 2. `coding-style.md` の判断基準の適用 🔵

**信頼性**: 🔵 *project CLAUDE.md/coding-style.md「定数管理: GAME_CONFIG vs THEME」判断基準の適用*

「変更するとUIの見た目が変わるか」を基準に、色・フォント・スペーシングのみを本ファイルに含める。報酬・価格・確率等のゲームバランスに関わる値は含めず、TASK-0005の `game_balance.gd` との責務分離を厳守する。

### 3. 品質グレード色の設計根拠 🟡

**信頼性**: 🟡 *data-model.mdの `MaterialInstance.Quality` 列挙（D=1〜S=5）に対応させた妥当な推測。具体的な色相はデザイン文書に確定記載がないためプレースホルダ*

data-model.mdで定義された品質グレード（D/C/B/A/S）はUI上で視覚的に区別される必要があると推測されるため、グレードごとの表示色を定義する。ただし具体的な色相・彩度は本タスク時点では暫定値であり、design-guide.mdの水彩ファンタジースタイルへの本格適用は後続のUI実装タスクで見直す前提とする。

## 動作確認要件

### 確認項目1: 静的アクセス可能性の確認 🔵

**信頼性**: 🔵 *完了条件「インスタンス化不要でアクセスできる」より（TASK-0005と同様の確認観点）*

**Given**: `theme.gd` が作成された状態
**When**: 別のGDScriptファイル（例: 一時的な検証用シーンのスクリプト）から `Theme.COLOR_BACKGROUND_PRIMARY` を参照する
**Then**: インスタンス化なしに `Color` 型の値が取得できる

**確認方法**: Godotエディタのスクリプトエディタで検証用の一時コードを実行し、出力を目視確認する（確認後は一時コードを削除する）

### 確認項目2: GAME_CONFIGとの責務分離確認 🔵

**信頼性**: 🔵 *完了条件「ゲームバランスに関わる値が混入していない」より*

**Given**: `theme.gd` に定義された全定数
**When**: 各定数が「変更するとゲームバランスが変わるか」を1件ずつ確認する
**Then**: 全定数が「UIの見た目のみに影響する」に分類され、価格・倍率・ターン数等のバランス値が混入していない

**確認方法**: 目視でのチェックリスト確認（`coding-style.md`の判断基準フローチャートを適用）

## 注意事項

- 本タスクは「基本的な見た目調整」レベルに留め、design-guide.md記載の水彩ファンタジースタイル（パステルカラー・ふんわり影・角丸統一等）の厳密な移植は行わない。詳細なビジュアル実装が必要になった段階で `theme.gd` を拡張する

- 品質グレード色（D〜S）は暫定値であり、実際のUI実装時に視認性・アクセシビリティの観点で見直しが必要になる可能性がある
