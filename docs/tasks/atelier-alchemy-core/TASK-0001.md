## 実装詳細

### 1. プロジェクトディレクトリ・Godotバージョンの決定 🔵

**信頼性**: 🔵 *architecture.md「エンジン・言語制約」より*

- Godot 4.x系の最新安定版を採用する（具体的なマイナーバージョンは着手時点の最新安定版。architecture.md「技術的制約」に準拠）
- ディレクトリ名は `atelier-godot/`（プロジェクトルート直下）を推奨する。architecture.md のディレクトリ構造案がこの名称を前提にしているため、変更する場合は以降の全タスクファイル・設計文書の参照パスに影響することに留意する
- 既存の `atelier-guild-rank/`（Phaser3+TS）・`Assets/`（Unity）とは完全に独立したディレクトリとし、依存関係を持たせない

**実装ファイル**: `atelier-godot/project.godot`

### 2. Godotエディタでのプロジェクト作成 🟡

**信頼性**: 🟡 *Godot公式のプロジェクト作成手順から妥当な推測（本プロジェクト固有の記載はarchitecture.mdになし）*

手順:
1. Godot 4.x エディタを起動し、「新規プロジェクト」を選択
2. プロジェクトパスを `atelier-godot/` に設定（プロジェクトルート = `C:\Users\syagu\Desktop\work\UnityProjects\atelier\atelier-godot`）
3. レンダラーは初期値（Forward+ 等）のままで問題ない。ターン制ゲームであり高度なグラフィック要件はない（NFR-001参照）
4. プロジェクト名を「Atelier Alchemy Core」等、プロジェクトの性質が分かる名前に設定
5. 空のプロジェクトとして作成し、一度エディタ上で開いて `project.godot` が生成されることを確認する

### 3. `.gitignore` の設定 🟡

**信頼性**: 🟡 *Godot公式テンプレート `.gitignore` を本プロジェクトに適用する妥当な推測*

Godotエディタが自動生成する `.godot/`（インポートキャッシュ等）はリポジトリに含めない。

```gitignore
# atelier-godot/.gitignore
.godot/
*.translation
export.cfg
export_presets.cfg
```

`export_presets.cfg` はエクスポート設定に機密情報や環境固有パスを含みうるため除外する（security.mdの「機密情報の管理」原則に準拠）。

### 4. プロジェクト設定の最小確認 🟡

**信頼性**: 🟡 *Godot標準機能から妥当な推測*

- 「プロジェクト設定」→「アプリケーション」→「実行」で、メインシーンは本タスク時点では未設定のままでよい（`scenes/main.tscn` はTASK-0002以降で作成）
- 解像度・ウィンドウサイズはデフォルトのままでよい（UI設計の詳細確定はPhase 1のスコープ外）

## 動作確認要件

### 確認項目1: プロジェクトの起動確認 🔵

**信頼性**: 🔵 *完了条件「Godotエディタで起動できる」より*

**Given**: `atelier-godot/project.godot` が作成された状態
**When**: Godot 4.xエディタで当該プロジェクトを開く
**Then**: エラーダイアログなしにプロジェクトマネージャ・エディタが起動し、空のシーンツリーが表示される

**確認方法**: Godotエディタを手動起動し、目視確認する（本タスクはDIRECTタスクのためGUTテストは対象外）

### 確認項目2: Gitでの差分確認 🔵

**信頼性**: 🔵 *完了条件「意図した差分のみ」より*

**Given**: `.gitignore` を設定済みの `atelier-godot/` プロジェクト
**When**: `git status` を実行する
**Then**: `.godot/` 等の生成物が追跡対象に含まれず、`project.godot` と `.gitignore` のみが新規ファイルとして表示される

**確認コマンド**: `git status atelier-godot/`
