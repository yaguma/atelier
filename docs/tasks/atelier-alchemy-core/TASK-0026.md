## 実装詳細

### 1. 逆算推薦ロジック `SeedRecommender` 🟡

**信頼性**: 🟡 *REQ-008「注文生産」、data-model.md `DailyRequest.preferred_category`, `TraitDefinition.category` より妥当な推測。具体的なマッチングアルゴリズムは要件定義に明記されておらず実装フェーズでの判断*

`DailyRequest` は `preferred_category`（`TraitDefinition.Category` — CONTRIBUTION/REWARD）のみを保持し、特定の特性IDまでは指定しない（data-model.md）。そのため「逆算」は、種の `possible_traits` のいずれかが `preferred_category` に属する `TraitDefinition` であるかどうかで判定する。

```gdscript
# res://features/garden/logic/seed_recommender.gd
class_name SeedRecommender

static func recommend_seeds(
	available_seeds: Array[SeedDefinition],
	daily_request: DailyRequest,
	trait_lookup: Dictionary,  # StringName -> TraitDefinition
) -> Array[SeedDefinition]:
	if daily_request == null:
		return []
	var recommended: Array[SeedDefinition] = []
	for seed_def in available_seeds:
		if _matches_preferred_category(seed_def, daily_request.preferred_category, trait_lookup):
			recommended.append(seed_def)
	return recommended

static func _matches_preferred_category(
	seed_def: SeedDefinition,
	preferred_category: TraitDefinition.Category,
	trait_lookup: Dictionary,
) -> bool:
	for trait_id in seed_def.possible_traits:
		var trait_def: TraitDefinition = trait_lookup.get(trait_id)
		if trait_def != null and trait_def.category == preferred_category:
			return true
	return false
```

`trait_lookup`（`StringName` から `TraitDefinition` への辞書）は、種の `possible_traits`（文字列IDの配列）から実際の `TraitDefinition.category` を解決するために必要であり、呼び出し元（GameState経由、またはマスターデータ管理側）が構築して渡す想定とする。純粋関数の原則（外部状態を参照しない）を維持するため、`trait_lookup` は引数として明示的に渡す。

**実装ファイル**: `features/garden/logic/seed_recommender.gd`
