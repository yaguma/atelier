## タスク概要

`GameState` Autoload（Imperative Shell）に、庭のスロット管理を担う `plant_seed()` と `harvest()` メソッドを実装する。data-model.mdで定義された `garden_slots: Array[SeedDefinition]`（型付きArray、null要素で空きスロットを表現）を状態として保持し、REQ-001（種を選択して植える）・REQ-002（スロット数のみで植栽数を制限、マス目や隣接関係は要求しない）を満たす。`harvest()` は内部でTASK-0022の `GrowthCalculator` とTASK-0023の `TraitRoll` を呼び出し、収穫可否判定・品質計算・特性付与を行った上で `MaterialInstance` を生成し `inventory` に追加する。architecture.mdが調合フロー（`AlchemyResolver.craft()`）で採用した「Imperative Shellはビジネスロジックを持たず、Functional Coreの呼び出し結果を状態に反映するのみ」という設計原則を、庭の収穫フローにも同様に適用する。

## 実装詳細

### 1. `garden_slots` の型付きArrayによる状態表現 🔵

**信頼性**: 🔵 *data-model.md「修正(2026-07-09、Godotアーキテクトレビュー Warning#4対応): 無型Arrayは型安全性の抜け穴になるため型付けした」より*

```gdscript
# res://autoload/game_state.gd（抜粋）
extends Node

signal garden_updated
signal inventory_updated

var garden_slots: Array[SeedDefinition] = []
var garden_planted_turns: Array[int] = []
	# 🟡 新設: data-model.mdは garden_slots: Array[SeedDefinition] のみを示すが、
	# GrowthCalculator（TASK-0022）の成熟・枯死判定には「植えてから何ターン経過したか」
	# の情報が必須であり、SeedDefinitionは静的マスターデータのためターン経過は保持できない。
	# garden_slotsと同じインデックスで対応する経過ターン記録用の並行配列として追加する。
var inventory: Array[MaterialInstance] = []
var garden_slot_count: int = 4
	# 🟡 REQ-002のスロット数上限。具体値はTBD（庭拡張により恒久投資で増加しうる、REQ-301参照）

func _ready() -> void:
	garden_slots.resize(garden_slot_count)
	garden_planted_turns.resize(garden_slot_count)
	garden_planted_turns.fill(-1)
```

`garden_slots` はGodot 4のtyped Arrayとしてnull要素を許容し、空きスロットをnullで表現する（data-model.md記載の設計方針）。`garden_planted_turns` はdata-model.mdに明記されていない追加の状態だが、REQ-003（成熟ターン数管理）・REQ-004（放置による品質上昇）を実現するために必須であり、本タスクで新設する 🟡。

**実装ファイル**: `autoload/game_state.gd`

### 2. 植栽処理 `plant_seed` 🔵

**信頼性**: 🔵 *REQ-001「手持ちの種から植える素材を選択できる」、REQ-002「スロット数のみで植栽数を制限」、EDGE-002「満杯時は植栽拒否」より*

```gdscript
func plant_seed(seed_def: SeedDefinition, slot_index: int) -> bool:
	if slot_index < 0 or slot_index >= garden_slots.size():
		return false
	if garden_slots[slot_index] != null:
		return false  # EDGE-002: 対象スロットが既に使用中
	garden_slots[slot_index] = seed_def
	garden_planted_turns[slot_index] = current_turn
	garden_updated.emit()
	return true
```

`slot_index` はUI（GardenPanel、TASK-0025）が選択した空きスロットを指定する前提とする。REQ-002により「マス目や隣接関係」の判定は一切行わず、対象インデックスが空きかどうかのみを検証する。`current_turn` は `GameState` が別途保持するターン経過カウンタ（他フェーズのターン管理実装に依存する想定）を参照する 🟡。

**実装ファイル**: `autoload/game_state.gd`

### 3. 収穫処理 `harvest` 🔵

**信頼性**: 🔵 **設計判断（2026-07-09相当の方針を踏襲）**: dataflow.md「機能1」シーケンス図はUI（GardenPanel）が `GrowthCalculator` / `TraitRoll` を直接呼び出す構成を示しているが、architecture.mdが調合フロー（機能2）で確立した「Imperative Shell（UI）はビジネスロジックを持たず、GameStateの単一メソッド呼び出しに集約する」原則（`GameState.craft()` の設計判断）を庭の収穫フローにも一貫して適用し、`GrowthCalculator` と `TraitRoll` の呼び出しをGameState内部に集約する 🟡

```gdscript
func harvest(slot_index: int, rng_seed: int) -> MaterialInstance:
	var seed_def: SeedDefinition = garden_slots[slot_index] if slot_index >= 0 and slot_index < garden_slots.size() else null
	if seed_def == null:
		return null
	var turns_since_planted: int = current_turn - garden_planted_turns[slot_index]
	var turns_since_maturity: int = turns_since_planted - seed_def.maturity_turns
	if not GrowthCalculator.can_harvest(seed_def, turns_since_planted, turns_since_maturity):
		return null  # EDGE-003: 未成熟または枯死済みは収穫不可

	var quality: MaterialInstance.Quality = GrowthCalculator.calculate_quality(seed_def, turns_since_maturity)
	var trait_id: StringName = TraitRoll.roll_trait(seed_def, rng_seed)
	var traits: Array[StringName] = [] if trait_id == &"" else [trait_id]
	var material := MaterialInstance.new(_generate_material_id(), quality, traits)

	inventory.append(material)
	garden_slots[slot_index] = null
	garden_planted_turns[slot_index] = -1

	garden_updated.emit()
	inventory_updated.emit()
	return material
```

`rng_seed` は呼び出し元（UI）が `RngService`（Autoload、TASK-0004）から取得して渡す想定とし、`GameState` 自身も `RngService` を直接参照せず引数として受け取る（`TraitRoll` の非依存設計との一貫性を保つ）🟡。

**実装ファイル**: `autoload/game_state.gd`

### 4. 枯死素材の扱い 🟡

**信頼性**: 🟡 *REQ-005「規定ターン数を超えて放置された素材を枯死（全損）させなければならない」より妥当な推測*

`harvest` は枯死済みスロットに対して `null` を返す（収穫失敗）のみで、スロットの自動クリアは行わない。枯死素材をスロットから除去する操作（EDGE-003の収穫拒否とは別に、プレイヤーが明示的に「除去」を選択するUI操作、またはターン経過時にシステムが自動でスロットを空ける処理）は、本タスクのスコープ外とし、TASK-0025（GardenPanel UI）またはターン進行処理（他フェーズ）で扱う方針とする。

**実装ファイル**: `autoload/game_state.gd`（本タスクでは実装しない、設計上の言及のみ）
