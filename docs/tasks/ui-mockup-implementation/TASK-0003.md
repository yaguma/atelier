**信頼性**: 🔵 *モックアップ02〜05 `.sidebar` より*

- インベントリ行: space-between / font-size 11px + 下線
- ショップボタン: margin-top auto / セカンダリ pill型 / font-size 11px

**実装ファイル**: `src/shared/presentation/ui/components/SidebarUI.ts`

**信頼性**: 🔵 *dataflow.md より*
