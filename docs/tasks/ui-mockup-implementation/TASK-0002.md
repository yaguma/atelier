## 実装詳細

### 1. ヘッダーレイアウト 🔵

**信頼性**: 🔵 *モックアップ02〜05 `.header` より*

- 背景 `Colors.surface.header` (#FDFAF5) / 下線 `Colors.border.subtle` 1px / padding 8px 16px
- ランクバッジ: pill型 bg `Colors.text.accent` (#D4A76A) font-size 12px
- 昇格ゲージ: max-width 120px / height 8px / fill #D4A76A
- HUD項目: 日数・Gold・AP を font-size 12px font-weight 500
- セパレーター: width 1px height 16px bg #E8E0D6

**実装ファイル**: `src/shared/presentation/ui/components/composite/HUDBar.ts`

### 2. データ契約の維持 🔵

**信頼性**: 🔵 *既存 HUDBar.ts 実装より*

既存の `MockupHUDBarData` 互換フィールド（currentRank/promotionGauge/remainingDays/gold/actionPoints/maxActionPoints）と `updateFromHeader()` / `update()` API を維持する。

### 3. ゲージ色・点滅ロジックの維持 🔵

**信頼性**: 🔵 *既存 calcPromotionGaugeColor / calcRemainingDaysStyle より*

昇格ゲージ色分け・残り日数の色分けと点滅Tweenの既存ロジックを維持する。
